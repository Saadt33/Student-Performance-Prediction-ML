# 🎓 Student Performance Prediction using Machine Learning

**Predicting Student Academic Performance Through Machine Learning**

## 🚀 About

Student Performance Prediction is a Machine Learning project that analyzes student academic data to understand the factors influencing academic performance and predict student grades.

The project uses a CSV dataset containing information about students, including nationality, grade levels, attendance, study hours, classroom participation, and other academic factors.

Multiple classification algorithms are implemented to analyze student performance and compare prediction results.

🎯 **Goal:** Explore how Machine Learning can help understand student performance and identify the factors that influence academic outcomes.

## 🧠 Key Features

📊 **Data Analysis**
- Load and explore student data from CSV files.
- Analyze different academic and behavioral factors.
- Identify patterns affecting student performance.

🧹 **Data Preprocessing**
- Prepare and clean the dataset.
- Handle categorical and numerical features.
- Transform data for Machine Learning models.

🤖 **Machine Learning**
- Implement multiple classification algorithms.
- Train and evaluate predictive models.
- Compare model performance and accuracy.

📈 **Data Visualization**
- Performance comparison graphs.
- Confusion Matrix.
- Correlation Heatmaps.
- Additional charts for exploring data patterns.

## 📊 Dataset Features

The dataset includes different student-related attributes:

- Nationality
- Grade Level
- Number of Raised Hands
- Attendance
- Hours Studied
- Other academic and behavioral factors
